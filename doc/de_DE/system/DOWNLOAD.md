# Download deines VPN Profiles

Nimm den Downloadlink für dein entsprechendes System, lade das ZIP-File herunter und entpacke es. Dann lädst du einfach die client.ovpn in deinen OpenVPN-Client und dertig ist das System konfiguriert.

Nach dem Start der Verbindung musst du nur noch deinen Benutzernamen und dein Passwort eintragen.
